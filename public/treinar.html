💡 Como funciona o roteiro
Pense em etapas como momentos da conversa:

Etapa 1 → Cliente diz "oi" → Atendente pergunta o equipamento
Etapa 2 → Cliente diz "celular" → Atendente pergunta o problema
Etapa 3 → Cliente descreve o problema → Atendente dá o orçamento

Você define o que o atendente responde e para qual etapa a conversa avança.
